# Écran Domaine

## Objectif

Lister les auteurs de référence d'un thème sociologique, avec une phrase
d'accroche pour chacun.

## Accès

- Depuis l'[accueil](/documentation/guide/accueil), en touchant un domaine.
- Adresse `/d/<identifiant>` (par exemple `/d/deviance`).

## Éléments de l'interface

| Élément | Description |
|---|---|
| Titre | Nom du domaine |
| Texte de présentation | Ce que le domaine recouvre, en une phrase |
| Compteur | « N auteurs de référence » |
| Liste d'auteurs | Initiales, nom, dates, courant, accroche |

## Actions et résultats

| Action | Résultat |
|---|---|
| Toucher un auteur | Ouvre sa [fiche](/documentation/guide/fiche-auteur) |
| Flèche ← | Revient à l'écran précédent |

## Cas particuliers

Un même auteur apparaît dans plusieurs domaines : Bourdieu figure par exemple
dans Classes sociales, Éducation, Culture, Corps et mœurs, Mobilité sociale et
Famille.

## Erreurs possibles

Un identifiant de domaine inconnu affiche « Introuvable — Ce domaine n'existe
pas », avec un retour vers l'accueil et la recherche.

## Navigation

Domaine → fiche auteur → filiations de cette fiche.
